# CodeAlpha_Blockchain-Development
Two Solidity smart contracts built and tested in Remix IDE. Task 1: Simple Storage with increment/decrement functions and value retrieval. Task 2: Multi-Send contract that splits and distributes Ether equally among multiple recipient addresses using a payable function and loop.
# Solidity Smart Contract Tasks

This repository contains two Solidity smart contracts built and tested using Remix IDE.

**Task 1 – Simple Storage:** Stores an integer value on-chain with `increment()` and `decrement()` functions to modify it by 1, and a `getValue()` function to read the current value.

**Task 2 – Multi-Send:** A payable contract that accepts an array of recipient addresses and equally splits and distributes the received Ether among them in a single transaction, using safe transfer checks and event logging.

Both contracts were compiled, deployed, and tested on Remix VM using test accounts to verify correct behavior.
